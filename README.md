# DSH PPT Agent

面向高密度阅读型 PPT 报告的 DSH 插件。它不是“一句话出图”的生成器，而是一条可分段确认、可分别迭代的报告产线。

## 安装

```bash
dsh plugin --profile web add github:<你的用户名>/dsh-ppt-agent
```

私有仓库需要在本地配置 GitHub 凭据后再安装。

## 四个技能

| 技能 | 作用 | 输出 |
|---|---|---|
| `ppt-intake` | 把用户提交或 AI 扒取的内容整理成可追溯的素材台账 | `materials.yaml` |
| `ppt-logic` | 按报告类型梳理页序大纲，判定大/小报告，逐页写论点并引用素材 ID | 页序列大纲 |
| `ppt-layout` | 用逻辑区块（全幅/分列/主从/自由）把每页翻译成版式方案 | 版式方案 |
| `ppt-visual` | 套用视觉基因与元素库，确定性渲染成 pptx 或 `deck.json` | 交付文件 |

## 使用方式

新开会话后直接描述任务，例如：

> 帮我做一份 Q3 经营复盘 PPT，先整理素材。

也可以点名某个环节：

> 用 ppt-intake 整理这段材料：……

每个环节产出后会停下来等确认；确认后才进入下一环节。用户明确说“跳过确认”时才连续执行。

## 视觉约定

- 页面 A4 横向，四周 20mm 页边距，内容区 257mm × 170mm。
- 字体微软雅黑，默认纯黑；标题 24pt，正文 10pt，一级标题 13pt 加粗。
- 页码右上角，封面、目录、章节页不显示。
- 一页最多两种强调手段。
- 表格只保留横线，图表去掉外框。
