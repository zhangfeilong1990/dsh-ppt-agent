# PPT 版面设计（Layout）

## 职责边界

决定**每页用几个区块、每个区块放什么、标题用哪种变体**。不生成正文，不选字体颜色，不直接写 pptx。

## 输入

- `ppt-logic` 产出的、已经用户确认的页序列大纲（含 `scale`）。

## 必读资源

执行前读取本 skill 的版式底座定义：

- `../../assets/layout-base-v1.0.yaml`

该文件定义页面结构、标题变体、区块模型和 Insight 页规则。下文规则与文件冲突时，以文件为准。

## 页面结构

A4 横向，四周页边距 20mm，内容区 257mm × 170mm。

### 标题槽（三种变体，按页选择）

| 变体 | 形态 | 适用 |
|---|---|---|
| `variant_A` 引导线式 | 左上角标题文字，下方一条**固定位置断开**的水平线（总宽 257mm：左段 180mm + 断开 15mm + 右段 62mm） | 常规正文页 |
| `variant_B` 总结框 | 内容区顶部全宽矩形，高约 22mm，内嵌一句话结论，字号 16pt | 需要一句话总结的页 |
| `variant_C` 无标题 | 不放标题 | 纯图表页、大图页、标题已嵌入图形内的页 |

规则：

1. 每页最多一个标题槽；`variant_B` 与 `variant_A` **不要同时出现**。
2. `variant_B` 任何页面都可以调用，不限于特定页型。
3. 封面、目录页不使用 `variant_A`，用各自的版式。

## 逻辑区块模型

不预设死网格，用四种区块组合表达版面：

| 区块 | 含义 | 常见用法 |
|---|---|---|
| `full` 全幅 | 横跨内容区 | 顶部总结框、底部全局备注、全宽图表 |
| `columns` 平铺分列 | 按比例横向切分，左右两区最常见（6:4、5:5、7:3） | 左文右图、左右对比、多栏并列 |
| `main_side` 主从 | 一个大区块 + 一个窄辅助区 | 左侧大图/长文，右侧补充说明或数据卡片 |
| `freeform` 自由排版 | 只给起始坐标与最大边界，内部按图形逻辑自排 | 时间线、流程图、矩阵、组织架构 |

规则：

1. **不强制矩形网格**：区块只约束大致区域和左右边界，内部元素可以是文字、图表、异形图形的组合。
2. 高信息密度页面允许「全幅 + 分列 + 自由」上下叠放，例如顶部总结框 + 下方左时间线右三张图。
3. 一页区块数量建议不超过 4 个；超过时提示用户拆页。

## 大/小报告模板族

| `scale` | 模板族 | 页序 |
|---|---|---|
| `large` | 大报告模板族 | 封面 → 目录 → 正文（章节页）→ Insight（可选）→ 附件（可选） |
| `small` | 小报告模板族 | 正文 1–2 页；不加封面目录；附件可选 |

小报告直接复用大报告正文的母题，不做单独的封面和目录。

## Insight 页

- 位置：正文之后、附件之前；在目录中**单独成章**。
- 版式：与正文页同源，可复用任意正文区块组合。
- 标题：文字必须以 `Insight` 开头。
- 内容：以编号或卡片形式列出启示/建议，不写大段散文。

## 输出格式

```yaml
template_id: 大报告-汇报型-v1
scale: large
global:
  gene_id: 品牌基因-v1
pages:
  - seq: 1
    motif_id: cover-A
    title_variant: variant_C
    blocks:
      - type: full
        slots:
          title: "2026 Q3 经营复盘"
          subtitle: "华东区专项"
          date: "2026-10-15"
  - seq: 3
    motif_id: content-结论+三证据
    title_variant: variant_A
    blocks:
      - type: full
        slots:
          summary_box: "华东区贡献 68% 增量，但增速被华南反超"
      - type: columns
        ratio: "6:4"
        slots:
          left: { region: 正文, h1: "增长结构", body_ref: "M-001,M-007" }
          right: { region: 图表, chart_zone: "bar-compare", source_line: "来源：财务系统，2026Q3" }
```

## 槽位命名约定

固定使用以下槽位名，便于 `ppt-visual` 无歧义消费：

- `title`：页标题
- `summary_box`：总结框内容
- `h1` / `h2`：区块内一级/二级标题
- `body`：正文文字
- `chart_zone`：图表区域，值写图表类型
- `source_line`：来源/口径
- `note`：备注
- `page_number`：页码位置由基因统一处理，版式层不重复声明

## 交互协议

1. 先说明本报告用的是哪个模板族、每页选了什么区块组合。
2. 以「页码 → 标题变体 → 区块结构 → 槽位内容」的表格展示，请用户确认。
3. 用户要求换版式时，只改对应页的 `motif_id` 或区块，不重排全文。
4. 用户确认后才交给 `ppt-visual`。
