# PPT 版面设计（Layout）

## 职责边界

决定**每页用几个区块、每个区块放什么、标题用哪种变体**。不生成正文，不选字体颜色，不直接写 pptx。

## 输入

- `ppt-logic` 产出的、已经用户确认的页序列大纲（含 `scale`）。

## 必读资源

执行前读取本 skill 的版式底座定义：

- `../../assets/layout-base-v1.0.yaml`
- `../../assets/exemplars.json`：20 套标杆范本，字段 `id` / `name` / `theme` / `taste` / `chrome` / `pages`；按报告类型选 `id`，再按 `pages` 的页序组合母题

该文件定义页面结构、标题变体、区块模型和 Insight 页规则。下文规则与文件冲突时，以文件为准。

## 页面结构

A4 横向，四周页边距 20mm，内容区 257mm × 170mm。

### 标题槽（三种变体，按页选择）

| 变体 | 形态 | 适用 |
|---|---|---|
| `variant_A` 引导线式 | 左上角标题文字，下方一条**固定位置断开**的水平线（总宽 257mm：左段 180mm + 断开 15mm + 右段 62mm） | 常规正文页 |
| `variant_B` 总结框 | 内容区顶部全宽矩形，高约 22mm，内嵌一句话结论，字号 16pt | 需要一句话总结的页 |
| `variant_C` 无标题 | 不放标题 | 纯图表页、大图页、标题已嵌入图形内的页 |

规则：

1. 每页最多一个标题槽；`variant_B` 与 `variant_A` **不要同时出现**。
2. `variant_B` 任何页面都可以调用，不限于特定页型。
3. 封面、目录页不使用 `variant_A`，用各自的版式。

## 逻辑区块模型

不预设死网格，用四种区块组合表达版面：

| 区块 | 含义 | 常见用法 |
|---|---|---|
| `full` 全幅 | 横跨内容区 | 顶部总结框、底部全局备注、全宽图表 |
| `columns` 平铺分列 | 按比例横向切分，左右两区最常见（6:4、5:5、7:3） | 左文右图、左右对比、多栏并列 |
| `main_side` 主从 | 一个大区块 + 一个窄辅助区 | 左侧大图/长文，右侧补充说明或数据卡片 |
| `freeform` 自由排版 | 只给起始坐标与最大边界，内部按图形逻辑自排 | 时间线、流程图、矩阵、组织架构 |

规则：

1. **不强制矩形网格**：区块只约束大致区域和左右边界，内部元素可以是文字、图表、异形图形的组合。
2. 高信息密度页面允许「全幅 + 分列 + 自由」上下叠放，例如顶部总结框 + 下方左时间线右三张图。
3. 一页区块数量建议不超过 3 个；超过时提示用户拆页或合并。

## 母题库

常用页面直接套用以下母题，不每次从零组合：

| 母题 | 区块结构 | 适用 |
|---|---|---|
| `content-技术效果对照` | 左右 5:5：左「技术/做法」，右「效果/结果」 | 一页讲清“做了什么、带来什么” |
| `content-单结论+板块` | 顶部总结框 + 下方单栏或两栏板块 | 正文只有一页时 |
| `content-多板块` | 上下或左右多个板块组合，板块内可再分条 | 正文分多个并列板块 |
| `appendix-列表` | 引导线标题 + 全幅编号列表 | 附件展开某板块细节 |
| `appendix-图片占位` | 引导线标题 + 全幅虚线占位框 | 效果图、示意图待补 |
| `appendix-双栏+表格` | 引导线标题 + 左右 5:5 + 底部全幅表格 | 车型/方案对比 |

新增母题时先在此表登记，再在 `layout-base-v1.0.yaml` 的 `motifs` 下补一条。

## 按内容形状选构图

先看内容是什么形状，再挑母题，不把内容塞进现成模板：

| 内容形状 | 构图 |
|---|---|
| 一个结论 + 一句支撑 | 一句话页：大字 + 大量留白 |
| 2–4 个并列项 | 卡片 / 四宫格 |
| 两个对象逐项对比 | 左右对比，逐行对齐 |
| 有先后或因果的 3–6 步 | 流程 / 时间线 |
| 数据 | 图表页，配一句读图结论 |
| 多维文本 | 表格 |
| 多个单元属于同一件事 | 一块大面 + 分区 |
| 分节过渡 | 章节页：一句话 + 进度 |

标题放不下时的顺序：**改短标题 > 降一档字号 > 拆成两页 > 压缩正文**，不要把标题缩到正文大小硬塞。

## 版式节奏

- 6 页以上的文稿，至少组合 4 种不同母题。
- 不连续 3 页使用同一种母题；连续两页要点后必须换一种区块。
- 封面与封底不显示页码。
- 并列信息优先用 `columns` 或 `main_side`，不要堆成长列表。

## 大/小报告模板族

| `scale` | 模板族 | 页序 |
|---|---|---|
| `large` | 大报告模板族 | 封面 → 目录 → 正文（章节页）→ Insight（可选）→ 附件（可选） |
| `small` | 小报告模板族 | 正文 1–2 页；不加封面目录；附件可选 |

小报告直接复用大报告正文的母题，不做单独的封面和目录。

## Insight 页

- 位置：正文之后、附件之前；在目录中**单独成章**。
- 版式：与正文页同源，可复用任意正文区块组合。
- 标题：文字必须以 `Insight` 开头。
- 内容：以编号或卡片形式列出启示/建议，不写大段散文。

## 输出格式

```yaml
template_id: 大报告-汇报型-v1
scale: large
global:
  gene_id: 品牌基因-v1
pages:
  - seq: 1
    motif_id: cover-A
    title_variant: variant_C
    blocks:
      - type: full
        slots:
          title: "2026 Q3 经营复盘"
          subtitle: "华东区专项"
          date: "2026-10-15"
  - seq: 3
    motif_id: content-结论+三证据
    title_variant: variant_A
    blocks:
      - type: full
        slots:
          summary_box: "华东区贡献 68% 增量，但增速被华南反超"
      - type: columns
        ratio: "6:4"
        slots:
          left: { region: 正文, h1: "增长结构", body_ref: "M-001,M-007" }
          right: { region: 图表, chart_zone: "bar-compare", source_line: "来源：财务系统，2026Q3" }
```

## 槽位命名约定

固定使用以下槽位名，便于 `ppt-visual` 无歧义消费：

- `title`：页标题
- `summary_box`：总结框内容；`summary_sentence` 为只要一句总结句时的槽位
- `section_summary`：板块级总结句，按 `ppt-logic` 的 `section_summary_policy` 使用
- `h1` / `h2`：区块内一级/二级标题（板块标题优先用 `h1`）
- `body`：正文文字
- `chart_zone`：图表区域，值写图表类型
- `image_placeholder`：图片占位，值写建议比例和占位尺寸
- `table_zone`：表格区域，值写列名
- `source_line`：来源/口径
- `note`：备注
- `insight`：正文最下面的 Insight 句
- `page_number`：由基因统一处理；位置必须与标题行水平居中对齐，版式层只声明、不重复计算

## 交互协议

1. 先说明本报告用的是哪个模板族、每页选了什么区块组合。
2. 以「页码 → 标题变体 → 区块结构 → 槽位内容」的表格展示，请用户确认。
3. 用户要求换版式时，只改对应页的 `motif_id` 或区块，不重排全文。
4. 用户确认后才交给 `ppt-visual`。
