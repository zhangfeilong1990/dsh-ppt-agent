# PPT 美化执行（Visual）

## 职责边界

只做**确定性渲染**：把 `ppt-layout` 的版式方案套上视觉基因和元素样式，产出可交付文件。不重新设计版式，不改论点，不增删页面。

## 输入

- `ppt-layout` 产出的、已经用户确认的版式方案。

## 必读资源

执行前读取：

- `../../assets/gene-v1.0.yaml`：视觉基因（页面、字体、字号、颜色、页码、Logo）
- `../../assets/elements-v1.0.yaml`：基础元素库（线条、色块、文本效果、项目符号）

所有字体、字号、颜色、线型必须取自这两个文件，不得自行发明。

## 视觉基因要点

| 项 | 值 |
|---|---|
| 页面 | A4 横向，297mm × 210mm，四周 20mm |
| 字体 | 微软雅黑（Microsoft YaHei），默认纯黑 `#000000` |
| 封面标题 | 32pt |
| 目录标题 | 28pt |
| 页标题 | 24pt |
| 总结段落 | 16pt |
| 一级标题 | 13pt，加粗 |
| 二级标题 | 11pt，加粗 |
| 正文 | 10pt |
| 图表内标签 / 图注 | 9pt |
| 备注 | 8pt，灰色 `#AEAEAE` |
| 页码 | 右上角，当前页 12pt、斜杠与总页数 10pt；封面、目录、章节页不显示 |
| 页眉页脚 | 无 |
| Logo | 仅封面右下角，高度不超过 0.3in |

## 元素库使用规则

按 `use_cases` 标签取用，不按外观临时发挥：

| 场景 | 取用元素 |
|---|---|
| 页面顶部全局框架线 | `L-01` 断开式实线（左 180mm / 断 15mm / 右 62mm） |
| 区块弱分隔、表格横线 | `L-02` 细浅灰线 |
| 一级标题下划线、结论强调 | `L-03` 加粗实线 |
| 一级标题引导、引语 | `L-04` 粗竖线 |
| 弱提示分隔 | `L-05` 虚线 |
| 顶部总结框、一级标题色块 | `S-01` 全宽深色矩形 |
| 柔和总结 | `S-02` 全宽浅色矩形 |
| 正文提示框、案例框 | `S-03` 浅灰无边框矩形 |
| KPI 卡片、图表容器 | `S-04` 细边框矩形 |
| 流程节点、标签 | `S-05` 圆角矩形 |
| 行内强调 | `T-01` 加粗 |
| 关键数字 | `T-02` 主题色 |
| 核心结论 | `T-03` 下划线 |
| 长段落重点 | `T-04` 浅色底纹 |
| 无序列表 | `I-01` 圆点 |
| 有顺序的要点、Insight 条目 | `I-03` 数字序号 |
| 优劣势、评估 | `I-04` 对勾/叉号 |

## 强调纪律

一页内同时使用的强调手段**不超过 2 种**，从以下选择：

1. **加粗**：关键名词、短句。
2. **下划线**：需要强制的结论句。
3. **主题色**：关键数字、专有名词。主题色暂用深蓝 `#1F4E79`；用户未确认前不用于大面积填色。
4. **浅灰底框**：整段提示性文字。
5. **左侧竖线**：引用或核心观点段落。

选择顺序：数据页优先「主题色 + 加粗」；文字页优先「加粗 + 浅灰底框」；结论页优先「总结框」。

## 表格与图表

- 表头：加粗，浅灰底 `#F2F2F2`，下边框线加粗。
- 表体：9–10pt 常规体，**只保留横向细线**，去掉竖线（高密度报告默认清爽型）。
- 对齐：文字左对齐，数字右对齐。
- 图表：只留水平网格线 `#E0E0E0`，去掉外框；图内不加标题；图例不超过 4 项时放右上角。
- 图表配色跟随主题色深浅变化，关键数据用主题色标出。

## 输出

二选一，按用户要求或环境能力：

1. **直接生成 pptx**：优先调用环境中可用的 pptx 生成工具或渲染插件。
2. **生成中间结构** `deck.json`：结构包含 `template_id`、每页 `motif_id`、区块坐标、槽位内容、字体字号颜色和元素引用 ID，供后续渲染器消费。

中间结构示例：

```json
{
  "template_id": "大报告-汇报型-v1",
  "page": { "size": "A4_Landscape", "margin_mm": 20 },
  "slides": [
    {
      "seq": 3,
      "motif_id": "content-结论+三证据",
      "title_variant": "variant_A",
      "title": "增长结构",
      "line": { "element": "L-01", "segments_mm": [180, 15, 62] },
      "blocks": [
        {
          "type": "full",
          "element": "S-01",
          "text": "华东区贡献 68% 增量，但增速被华南反超",
          "font": { "family": "Microsoft YaHei", "size_pt": 16, "color": "#FFFFFF" }
        }
      ]
    }
  ]
}
```

## 渲染检查

输出前自检：

1. 字号、颜色、线型是否都来自 gene/elements，没有临时值。
2. 页码是否只在正文页和附件页出现。
3. 一页强调手段是否超过 2 种。
4. 表格是否已去掉竖线。
5. 正文是否超出内容区（257mm × 170mm），超出的页需回退给 `ppt-layout` 拆页。

## 交互协议

1. 先说明将生成 pptx 还是 deck.json，并列出使用的元素 ID。
2. 生成后展示文件路径和页数，请用户检查。
3. 用户要求调整视觉时，只改对应元素或字号，不改版式结构；版式问题回退给 `ppt-layout`。
