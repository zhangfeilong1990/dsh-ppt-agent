# dsh-ppt 蒸馏笔记

来源：`dsh-ppt` 0.33.0 的 `SKILL.md`（MIT，作者 DSH 社区）。
用途：把成熟的报告方法论提炼成我们轻量产线的规则，不复制代码、不引入其依赖。

## 采用

### 1. 结论先行（Action Title）

- 除封面、目录、章节页外，每页标题必须是**完整的判断句**，不是名词标签。
- 反例：「项目背景」「数据分析」「周末到馆人次」。
- 正例：「异步评审把工程师周均例会耗时压缩 75%」。

对应：`ppt-logic` 的 `argument` 字段、`ppt-intake` 的 `■` 标题。

### 2. 反要点墙

- 单页普通要点不超过 5 条。
- 整套文稿不连续超过 2 页用「纯要点列表」。
- 并列信息升格为 KPI、卡片、对比、流程、矩阵。

对应：`ppt-layout` 的母题选择。

### 3. 出版级图表

- 单系列图表不要冗余图例。
- 网格线不超过 5 条细灰线。
- 关键柱/点用高亮，其余灰阶退后。
- 数据页左下角必须有真实 `source`。
- 学术/严谨对比用无竖线三线表。

对应：`ppt-visual` 的图表与表格规则。

### 4. 字号底线

- 投影场景正文不低于 13.5pt；超长内容拆页，不缩字。
- A4 印刷场景按 10pt 正文，属于不同介质，不冲突；同一份里不要混用两套假设。

对应：`gene-v1.0.yaml` 的字号体系。

### 5. 版式多样性

- 6 页以上的文稿，至少组合 4 种不同版式。
- 封面与封底不印页码。

对应：`ppt-layout` 的母题轮换。

### 6. 收尾要可执行

- 最后一页给明确的下一步：行动号召、里程碑、联系人，不只写「谢谢」。

对应：`ppt-logic` 的最后一页 `argument`。

### 7. 事实出处门禁（精简版）

- 禁止「数据来源：网络整理 / 公开资料」这类空出处。
- 每个量化页面必须能回指到素材台账或明确来源。
- 冲突数据标区间，缺数据改定性图示。

对应：`ppt-intake` 的 `#M-xxx` 与 `gaps`、`ppt-logic` 的 `source_notes`。

## 暂不采用

| 项 | 原因 |
|---|---|
| 20 套标杆范本、24 主题、6 母版 | 我们是轻量产线，先跑通结构与对象画布 |
| 零资料联网深研四步闭环 | 我们的素材由用户提交，不默认联网 |
| `dataModel` 现场推演 | 需要数据源绑定，超出当前范围 |
| Remotion 视频导出 | 与 PPT 报告无关 |
| 20 套行业蓝图 | 可后续按需摘录，不整体引入 |

## 可选的直接调用

需要“高质量成稿”而不是“工具内编辑”时，可以直接用 `dsh-ppt` 的工具：

- `ppt_create({ title, content, theme: 'auto', exemplar: 'auto' })`：一次生成 HTML + PPTX + JSON。
- `ppt_templates({ topic })`：零资料时先出分镜策划。
- `ppt_check` / `ppt_render`：校验与看图。

我们的画布与它分工：

- 画布：结构规划、对象拖动、快速改。
- `dsh-ppt`：设计成稿、导出原生可编辑 PPTX。
