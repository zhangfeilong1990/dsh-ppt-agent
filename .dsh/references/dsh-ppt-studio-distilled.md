# dsh-ppt-studio 蒸馏笔记

来源：`dsh-ppt-studio` 1.2.7 的 `ppt-studio-craft` 与 `ppt-studio-data` 手册。
用途：把叙事、构图、数据呈现的规则提炼进我们的轻量产线。

## 采用

### 1. 叙事七问（写页序前）

1. 听众是谁、已经知道什么？
2. 一句话结论是什么？
3. 支撑它的 2–4 个理由是什么？
4. 每个理由的证据是什么？
5. 听众可能怎么反驳，哪页先挡？
6. 需要他们做什么？
7. 哪些内容应进讲稿而不是页面？

对应：`ppt-logic` 的页序设计前检查。

### 2. 标题连读

排完页后只读标题，看是否是一段连贯论证。

- ✗ 背景 / 现状 / 问题 / 方案 / 优势 / 规划 / 总结
- ✓ 交付周期从 32 天压到 19 天 / 卡点在两处人工交接 / 我们改了三件事 / 试点 6 组的结果 / 下一步：全线推广

对应：`ppt-logic` 的 `argument` 校验。

### 3. 标题放不下时的顺序

**改短标题 > 降一档字号 > 拆成两页 > 压缩正文**。不要靠把标题缩到正文大小硬塞。

对应：`ppt-layout` 的槽位溢出处理。

### 4. 按内容形状选构图

先看内容是什么形状，再挑构图，不把内容塞进现成模板。

| 内容形状 | 构图 |
|---|---|
| 一个结论 + 一句支撑 | 一句话页：大字 + 大量留白 |
| 2–4 个并列项 | 卡片 / 四宫格 |
| 两个对象逐项对比 | 左右对比，逐行对齐 |
| 有先后或因果的 3–6 步 | 流程 / 时间线 |
| 数据 | 图表页，配一句读图结论 |
| 多维文本 | 表格 |
| 多个单元属于同一件事 | 一块大面 + 分区 |
| 分节过渡 | 章节页：一句话 + 进度 |

对应：`ppt-layout` 母题库的选择规则。

### 5. 构图签名

每页动笔前写一行：`页任务 → 构图手法 → 轮廓语言`。
下一页对比：任务不同但签名相同 → 换手法；任务相同 → 沿用。

对应：`ppt-layout` 的版式轮换。

### 6. 版式卫生

- 对齐有锚：左边界、基线、间距来自同一套栅格。
- 一页一个焦点：面积或对比最强的那块。
- 对等对象用对分，不对等别硬凑均分。
- 节奏靠密度与构图，不靠中途换底色。

对应：`ppt-layout` 与 `ppt-visual`。

### 7. 图片按角色分派

- 证据类图：保真优先，不裁关键信息。
- 照片类：统一比例与高度，主体不切。
- 装饰/背景图：允许出血，但文字压图前确认有干净区域。

对应：`ppt-visual` 的图片规则。

### 8. 图是证据还是装饰

- 承载结论的图：分类名、数值、单位、一句结论句，缺一不可；标签放图外。
- 装饰图：可以不带标签，但标注「示意」，且不能用来支撑页面结论。

### 9. 没有数据不要用图表

- 概念列举不要画成条形图，没有基数的百分比不要画柱。
- 图上每个量化标记必须来自权威值 + 显式比例换算。
- 非零基线必须在图上写明。

对应：`ppt-visual` 的数据诚实规则。

### 10. 选型与标签

- 一个数的大小/趋势 → 图表（bar 比大小，line 看趋势）。
- 精确值 → 表格或大字数字。
- 两三个数 → 大字数字块，不用图表。
- 占比 → 饼图只在 ≤5 类时可用，多了改横条或表格。
- 一张图只表达一个结论；同一页不放两张抢注意力的图。
- 柱状从 0 起；折线可不从 0，但注释说明。

对应：`ppt-visual` 的图表规则。

## 暂不采用

| 项 | 原因 |
|---|---|
| `deck.yaml` + 元素级 DSL | 我们用项目符号稿 + 画布对象 |
| `ppt_verify` 门禁数值 | 需要其引擎，不在我们轻量流程内 |
| 原生可编辑图表 + 内嵌工作簿 | 导出脚本暂用文本框 + 简单表格 |
| `expectedOverlaps` 声明制 | 画布自由拖动，暂不做重叠检测 |

## 可直接调用

需要严格版式与门禁时，用 `dsh-ppt-studio` 的工具（`ppt_new` / `ppt_check` / `ppt_verify` / `ppt_visual`），我们的画布继续做规划与快速调整。
