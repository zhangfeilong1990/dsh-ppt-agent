# 来源与许可

- 包：`dsh-ppt` 0.33.0
- 作者：DSH 社区（见原包 `package.json`）
- 许可：MIT
- 原始路径：`dsh-ppt/skills/dsh-ppt/references/` 与 `SKILL.md`

本目录是本地素材库，原样保存，供 `ppt-layout` / `ppt-visual` 需要时检索：

| 文件 | 用途 |
|---|---|
| `themes.md` | 24 套主题与色板 |
| `exemplars.md` | 20 套标杆范本与槽位契约 |
| `syntax.md` | Markdown/结构化幻灯片语法 |
| `data.md` | dataModel 推演与数据源绑定 |
| `research-plan.md` | 零资料调研与分镜策划 |
| `copywriting.md` | 文案与标题写法 |
| `advanced.md` | 高级图示、地图、等轴测 |
| `troubleshooting.md` | 常见问题 |

修改本目录前先确认上游版本；升级 `dsh-ppt` 后重新复制并更新本文件。
